# Woow LiteLLM

> **測試版**：尚未正式發佈。

本 add-on 由 WOOWTECH 打包，不是 BerriAI 的官方產品；LiteLLM 是 BerriAI 的專案名稱。

LiteLLM AI 閘道（OpenAI 相容）＋內建 PostgreSQL。與 Woow PaaS 同版 LiteLLM（1.104.0）、同一套 Woow 外掛
（ChatGPT 訂閱、多帳號）。在 Home Assistant 側邊欄直接開啟 LiteLLM 管理介面；同一台 HA 的其他 add-on 以
`http://<主機名>:4000` 連線。只支援 amd64，需要 Home Assistant 2026.5.0 以上。

說明見「說明文件」分頁（DOCS.md）。
